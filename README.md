# VyOS Panel — развёртывание контейнером на роутере

Панель управления парком VyOS ставится прямо на один из роутеров
как контейнер (podman встроен в VyOS) и управляет остальными узлами
через штатный HTTPS API. Проверено на `vyos-2026.10.01-0035-rolling`.

Версия 2.4 — полноценный GUI, а не только мониторинг: редактирование
интерфейсов и VLAN, файрвола (правила и группы), NAT (masquerade/DNAT),
статических маршрутов и OSPF, DHCP/DNS/NTP, VPN (WireGuard, IPsec
site-to-site, GRE/IPIP/SIT/L2TPv3-туннели, OpenVPN, L2TP/IPsec
remote-access), высокой доступности (VRRP, conntrack-sync, config-sync),
сервисов (syslog на серверы/SIEM, SNMP v2c/v3, LLDP, DDNS, DHCP-relay,
stunnel, PPPoE сервер и клиент). Каждое изменение — с предпросмотром
команд `set`/`delete` и автоматическим бэкапом конфигурации на роутере
с откатом в один клик. Учётки панели: администраторы и наблюдатели
(read-only), журнал действий.
